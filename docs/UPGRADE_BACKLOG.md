# 项目升级清单

## 必须完成（简历和面试核心）

- 安全 NL2SQL：SQLGlot AST 校验、只读账号、表/字段白名单、行数限制和超时。
- 指标语义层：销售额、退款率、客单价等指标的定义、来源、版本和示例 SQL。
- 权限和审计：角色、敏感字段、查询记录、模型计划、SQL 和结果均可追踪。
- LangGraph Checkpointer：验证任务中断后的恢复，而不是只保存聊天记录。
- 100 条以上独立评测集，包含错误问题、越权问题、复杂多表问题和工具异常。
- Docker Compose、pytest、GitHub Actions、README 和演示视频。

## 有余力再做

- PostgreSQL pgvector 和指标/Schema RAG。
- MCP 封装数据库查询和图表生成工具。
- 指数退避、熔断、幂等和故障注入。
- 结构化执行 Trace 和 p50/p95 延迟统计。
- 最小 Vue/SSE 页面。

## 暂不扩张

- K8s 生产化部署。
- PDF/OCR 和任意格式文件处理。
- 多行业、多数据库泛化。
- 为了数量拆分多个 Sub-agent。
- 没有原始报告支撑的准确率和失败率。

## 简历可用条件

只有在代码、测试、评测原始数据和演示都存在后，才把结果写进简历。指标使用真实运行结果，不预设“好看”的提升幅度。
